## About Twisted Tar

Twisted Tar is a luxury direct-to-consumer fashion house celebrating generational Lucknowi needlecraft. Founded in the historic heart of Awadh, we craft timeless three-piece ensembles, everyday two-piece pairings, and contemporary short tunics.

Every garment is hand-embroidered by women artisans across rural Lucknow, preserving historic court stitches including:
- **Bakhiya (Shadow Work)** — Fine herringbone needlework on the fabric's reverse.
- **Phanda (Millet Knots)** — Raised, rounded floral grain stitches.
- **Murri (Rice-Grain Knots)** — Elongated basmati-grain embroidery.
- **Jaali (Lattice Openwork)** — Delicate gossamer mesh created without cutting a single yarn.
- **Keel Kangan & Tepchi** — Graceful vine line tracery.

## Local Development

To run the storefront locally:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/uditdave1993-afk/twistedtar.git
   cd twistedtar
   ```

2. Open `index.html` directly in any modern web browser, or serve locally:
   ```powershell
   powershell.exe -ExecutionPolicy Bypass -File .\serve.ps1
   ```
   Then open `http://localhost:8080/` in your browser.
